# 🍽️ Swiggy Restaurant Intelligence Dashboard

An interactive and business-focused Power BI dashboard designed to analyse Swiggy restaurant data and generate meaningful insights into restaurant performance, customer ratings, pricing, cuisines, offers, and location-based trends.

---

## 📌 Project Overview

The **Swiggy Restaurant Intelligence Dashboard** is an interactive Business Intelligence project developed using Microsoft Power BI. The dashboard transforms raw restaurant data into meaningful visual insights that support data-driven decision-making.

The project provides both high-level executive insights and detailed restaurant-level analysis through interactive filters, parameters, drill-through, drill-down, and AI-powered analytics.

---

## 🎯 Purpose

The primary purpose of this project is to:

- Analyse restaurant performance across different locations.
- Understand customer rating and engagement patterns.
- Analyse restaurant pricing and price categories.
- Explore cuisine popularity and distribution.
- Analyse the impact of restaurant offers.
- Identify factors influencing restaurant ratings.
- Provide interactive and actionable business insights.

---

- **Microsoft Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures, calculated columns, and dynamic calculations
- **Data Modelling** – Data relationships and analytical structure
- **Kaggle** – Dataset source

---

## 📊 Data Source

**Source:** Kaggle – Swiggy Restaurant Dataset

The dataset contains restaurant-related information such as:

- Restaurant Name
- Location
- Cuisine
- Rating
- Number of Ratings
- Average Price
- Number of Offers
- Has Offer
- Pure Veg / Non-Veg information

The data was cleaned and transformed using **Power Query** before being used for dashboard development.
