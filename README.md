🍽️ Swiggy Restaurant Intelligence Dashboard
📌 Description and Purpose
An interactive Power BI dashboard designed to analyse Swiggy restaurant data and provide actionable insights into restaurant performance, customer ratings, pricing, cuisine trends, and location-based performance. The dashboard helps users explore data at both executive and detailed restaurant levels through interactive navigation and advanced Power BI features.
🛠️ Technology
Power BI
Power Query
DAX
Data Modelling
Data Visualization
📊 Data Source
Kaggle – Swiggy Restaurant Dataset
The dataset contains information related to restaurants, locations, cuisines, ratings, pricing, customer ratings/reviews, offers, and vegetarian options.
✨ Features and Highlights
📊 Executive Overview Dashboard with key performance indicators
📍 Location Performance Analysis using dynamic business metrics
🍜 Cuisine Analysis using interactive visualizations
⭐ Restaurant Rating Distribution
🔍 Interactive Slicers and Filters
🔄 Reset Filters functionality
🎯 Drill-through from location-level insights to restaurant performance
🔽 Drill-down Hierarchy: Location → Cuisine → Restaurant
🎨 Conditional Formatting for restaurant performance comparison
💰 Price Category Analysis
👥 Customer Engagement Analysis
🎁 Offer Impact Analysis
🤖 Key Influencers to identify factors influencing restaurant ratings
📈 Interactive and business-focused data visualizations
🔄 Last Refresh indicator for dashboard freshness
